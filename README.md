# Primeira API

Uma API simples de tarefas, criada para praticar desenvolvimento backend com Node.js, Express e TypeScript.

## O que pratiquei

- Criação de rotas para listar, cadastrar, atualizar e excluir tarefas.
- Uso de middlewares para validar os dados recebidos e verificar se uma tarefa existe.
- Organização do servidor e das rotas em arquivos separados.

As tarefas ficam em memória e são reiniciadas quando o servidor é encerrado.

## Tecnologias

- Node.js
- Express
- TypeScript
- Yarn

## Como executar

```bash
yarn install
yarn dev
